Say Less: Prompt Budget state machine

The question. What states, events and rules should govern a Level's Prompt Budget across Attempts? Does the budget reset every Attempt or drain across them? Does the same Prompt always play out the same way? What happens to a Prompt that's over budget, to tokens lost to a model error, and to an Attempt the player stops? When is a Level lost? Flip the rules on the right, then push the Level through the walkthroughs and see which answers feel right.

The Level here is a toy: a gap stands between the Companion and the flag. The Companion is a stand-in that only reports how each Attempt ends. In free play you decide the ending, or let the stand-in decide: it clears the gap only if the Prompt tells it to jump. Token counts are rough (about one per word); the game will count with gpt-tokenizer's cl100k_base.
