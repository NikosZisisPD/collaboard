# Phaser with TypeScript, inside a React page

The prototype is built with Phaser 4 in TypeScript, starting from Phaser's official React template, so the game canvas sits in a React page that holds the Prompt box, the Prompt Budget and the list of Attempts. Everything around the Companion is already JavaScript (the tokenizer, the calls to the local model and the Prompt Budget state machine), TypeScript and React are the developer's own stack, and saving a file reloads the game, which the live bonus Level depends on. Godot 4.7 was the alternative: its editor, tile tools and built-in text box are stronger, but a web build reaches JavaScript only through `JavaScriptBridge`, can't count tokens when the game runs from the editor, and needs a manual re-export after every change. Details are in [Choose the engine: Phaser or Godot](https://github.com/NikosZisisPD/collaboard/issues/7).
