# The Companion knows Places by name, not a map of the Level

The Companion's hidden instructions list the Level's Places by name (the edge, the switch, the flag) but give it no map; the game works out where each Place is and acts the Plan out tile by tile. In an experiment with the local 4B model, a map made it miscount tiles (1 of 4 natural Prompts cleared) and sometimes solve a Level from a vague Prompt, while named Places cleared every natural and counted Prompt and still failed the vague ones, so the Prompt stays the puzzle. Don't give the Companion a map, or let it re-plan while it acts, without re-running that experiment: either would let it fix the player's Prompt. Details are in [How the Companion turns a Prompt into actions](https://github.com/NikosZisisPD/collaboard/issues/8).
