# Levels are plain-text grids, and the game works out their Places

Each Level is a TypeScript module in `src/levels/` holding its Prompt Budget and a two-row text grid: what stands on each tile above, the ground below. The game works out the Places from the tiles, reading left to right, so the file never names them. Phaser loads Tiled maps natively, but a Level is a single lane of gaps, switches and doors with placeholder art, and on demo day an agent writes the bonus Level in front of the audience, who can read two lines of text but not a Tiled map. When a kind repeats, the Places are numbered from the left (gap 1, gap 2) and Switch 1 opens Door 1: in a check with the local model, ordinal names ("first switch", "second switch") made the Companion count tiles instead of naming Places, and even the intended Prompt failed. Don't change how Places are named without re-running the [duplicate Places check](https://github.com/NikosZisisPD/say-less/tree/research/duplicate-places-check/experiments/duplicate-places). Details are in [Level file format: Tiled or a plain-text grid?](https://github.com/NikosZisisPD/say-less/issues/12).
